## About me

I'm a **software developer and AI PhD researcher at TU Dublin** with a BSc in Computer Science and hands-on experience in full-stack development, computer vision and 3D technologies. I enjoy building complete systems—from practical applications to research-driven tools for understanding floorplans and exploring energy-aware building design.

## AI Projects

### ModelHub — Local AI Model Management

A **C# / .NET / Avalonia** desktop application for managing local AI models through **LM Studio**, with dedicated model loading and unloading controls, prompting, and a workflow designed for comparing multiple models.

### [ChemSolve — Computer Vision & 3D Molecular Visualisation](https://github.com/yuryk200/ChemApp-Final-Year-Project)

My Computer Science final-year project: an **Android application** that recognises hydrocarbon structures from images, processes them through a **Python/Flask** backend and displays interactive molecular models using **Unity**.

## Software Projects

### [ORF Gene Reader — Python Bioinformatics Tool](https://github.com/yuryk200/Gene-Reader)

A **Python** application that reads DNA sequences from FASTA files, identifies open reading frames and translates all six reading frames into amino-acid sequences.

### [Unity SDF Renderer — Runtime Molecular Visualisation](https://github.com/yuryk200/Unity-3D-SDF)

A **Unity / C#** component that parses molecular SDF files and creates interactive 3D representations of atoms and bonds at runtime, developed for the ChemSolve application.
